    Add to XCTrack

    1. In XCTrack (PRO), add a new Web page widget.
    2. Paste the widget URL above into the widget's URL field.
    3. Enable "Allow web page to access XCTrack data" for the widget.
    4. Set the widget's reload interval to 0 (the widget refreshes itself).
    5. In flight, long-press the widget to interact with it — that's how you open its own gear/settings overlay.
    Settings are also editable later from the widget's own gear icon.
